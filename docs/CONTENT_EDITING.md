# Content Editing Guide / कंटेंट एडिटिंग गाइड

For the tutor — how to change website content yourself, no developer needed.
टीचर के लिए — बिना Developer के खुद Website Content कैसे बदलें।

> First time? The developer must finish [SANITY_SETUP.md](./SANITY_SETUP.md) once. After that, everything below is for you.
> पहली बार? Developer को एक बार [SANITY_SETUP.md](./SANITY_SETUP.md) पूरा करना होगा। उसके बाद नीचे सब आपके लिए है।

---

## Open the editor / एडिटर खोलें

1. Open your browser and go to `https://your-website.com/studio`.
   ब्राउज़र में `https://your-website.com/studio` खोलें।
2. Log in with your Sanity account. / अपने Sanity Account से Log in करें।
3. Changes appear on the website within **1 minute** of clicking **Publish**.
   **Publish** दबाने के **1 मिनट** के अंदर बदलाव Website पर दिख जाते हैं।

**Golden rule / ज़रूरी बात:** always fill **both** the English and Hindi boxes.
हमेशा **English और Hindi दोनों** Box भरें।

---

## What you can edit / आप क्या बदल सकती हैं

| In the Studio sidebar | Controls on the website |
| --- | --- |
| **Site Settings** | Phone, WhatsApp, Email, Instagram, hero text & photo, trust badges |
| **About Teacher** | Your photo, bio, and credential badges |
| **Course** | The course cards |
| **Review** | Student reviews / testimonials |
| **Gallery Image** | Class photos |
| **Class Video** | YouTube class videos |
| **Expert Session** | Guest/expert session cards |
| **FAQ** | Questions & answers |

Anything you leave empty automatically shows sensible default text, so the site never looks broken.
जो आप खाली छोड़ेंगी, वहाँ अपने-आप default text दिख जाएगा — Website कभी खाली नहीं दिखेगी।

---

## Change your phone / WhatsApp / email / फ़ोन, WhatsApp, Email बदलें

1. Sidebar → **Site Settings**.
2. Edit **Phone Number**, **WhatsApp Number** (digits only, e.g. `917247400000`), **Email**, **Instagram URL**.
3. **Publish**. Every Call/WhatsApp button across the site updates automatically.

## Change the teacher section / टीचर सेक्शन बदलें

1. Sidebar → **About Teacher**.
2. **Photo** — upload your photo. **Bio** — write in English and Hindi.
3. **Credentials** — the small badges (e.g. `M.A. English (Gold Medalist)`, `CG SET Qualified`, `Assistant Professor of English — 7 Years`, `Spoken English Trainer — 5 Years`). Add/remove as needed.
4. **Publish**.

## Add a student review / नया Review जोड़ें

1. Sidebar → **Review** → **+** (create new).
2. Student Name, City, Rating (1–5), Review Text (English + Hindi), Photo (optional).
3. **Publish**. The newest reviews show first.

## Add a class photo / क्लास फोटो जोड़ें

1. Sidebar → **Gallery Image** → **+**.
2. Upload the photo, add a caption (English + Hindi), set a display order number.
3. **Publish**.

## Add a class video / क्लास वीडियो जोड़ें

1. Sidebar → **Class Video** → **+**.
2. Title (English + Hindi), paste the **YouTube link**.
3. **Publish**.

## Add / edit a course / कोर्स जोड़ें या बदलें

1. Sidebar → **Course** → **+** (or open an existing one).
2. Title, Duration, Features (add each point), tick **Is Most Popular?** for the highlighted card, set display order.
3. **Publish**.

## Add an FAQ / सवाल-जवाब जोड़ें

1. Sidebar → **FAQ** → **+**.
2. Question and Answer (English + Hindi), display order.
3. **Publish**.

## Add an expert session / Expert Session जोड़ें

1. Sidebar → **Expert Session** → **+**.
2. Title, Description, Date, Speaker name, Speaker photo, optional video URL.
3. **Publish**.

---

## Tips / सुझाव

- Photos should be under ~2 MB. / फोटो ~2MB से कम रखें।
- Lower "display order" numbers appear first. / छोटा "order" नंबर पहले दिखता है।
- Practice games' words/sentences are fixed in the code — ask the developer to change those. / Practice Games के Words/Sentences code में हैं — उन्हें बदलने के लिए Developer से कहें।
- For anything else, contact your developer. / बाकी किसी चीज़ के लिए Developer से संपर्क करें।
